# figurdiscover

موقع التحليل المالي والإحصائي — figurdiscover.com

- `index.html` : الموقع كاملاً في ملف واحد.
- `package.json` : يخبر Railway كيف يشغّل الموقع (خادم ملفات بسيط على المنفذ PORT).
- `supabase-setup.sql` : جدول حفظ بيانات المستخدمين، يُشغَّل مرة واحدة في Supabase > SQL Editor.

للتحديث: ارفع ملف `index.html` الجديد إلى هذا المستودع (Add file > Upload files > Commit)، وRailway ينشر التحديث تلقائياً خلال دقيقة.
